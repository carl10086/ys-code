架构总览

分层架构 + 事件驱动 Agent 系统

ys-code 采用清晰的分层架构：CLI 接口层、Agent 核心层、AI 抽象层、Session 持久化层、TUI 渲染层和 Web 服务层。通过 Agent 类和 runAgentLoop 实现状态化 Agent，事件订阅机制连接各层。

架构 事件驱动

核心参考：Claude Code 源码（refer/claude-code-haha/）和 Pi-mono 项目（refer/pi-mono/）

层级 位置 职责
CLI 接口层 src/main.ts 程序入口、命令行解析、启动协调
Agent 核心层 src/agent/ 状态化 Agent、消息路由、工具执行
AI 抽象层 src/core/ai/ Provider 注册表、多后端支持
Session 层 src/session/ 持久化、上下文管理
TUI 渲染层 src/tui/ Ink + React 终端界面
Web 服务层 src/web/ 预览服务器、HTTP API

文档风格指南

  • 文件名使用英文 kebab-case，无日期前缀
  • 技术术语保留英文原文（如 compact、tool call）
  • 代码块使用 TypeScript 语法高亮
  • 过时内容使用 状态: 已过时 标注
  • 文档间通过相对路径链接，避免绝对路径
  • 规格文档聚焦"做什么"和"为什么"，指南文档聚焦"怎么做"

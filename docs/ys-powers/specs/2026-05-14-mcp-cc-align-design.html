code-style hard rules · §4 
· 语言：TypeScript，与现有 ys-code 风格一致
· 日志：所有 MCP 相关日志走 logger.{warn,info,debug}
·       严禁 console.log / console.error / process.stderr 直接写
· 错误：自定义类 McpConnectionError，错误信息含 server 名
· 状态修改：只通过 transitionTo(currentState, nextKind, payload) 纯函数
· CLI 输出：用户可见走 console.log（CLI 正常 stdout，与 logger 区分）
· 文件原子写：writeMcpJson 必须 tmp + fs.renameSync
· schema 转换：未识别 combinator → Type.Any() + logger.debug 记录降级
· 测试：新增/修改函数必须有对应单测，bun test 通过

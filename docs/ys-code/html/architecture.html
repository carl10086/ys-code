ys-code Architecture
Layer 1
CLI / TUI / Web
Pattern Overview

分层架构 + 事件驱动 Agent 系统

ys-code 是一个分阶段逼近 Claude Code 的可控实现项目，采用分层架构与事件驱动 Agent 系统的核心模式。

清晰分离 CLI 接口层、Agent 核心层、AI 抽象层、Session 持久化层、TUI 渲染层和 Web 服务层，通过 Provider 抽象支持多后端（Anthropic/MiniMax）。

Layer 2 / Agent Core

状态化 Agent 实现

Agent 核心层负责状态化 Agent 实现、消息路由、工具执行和 Agent 循环控制。

关键抽象包括 Agent 类（状态化封装）、runAgentLoop（核心循环逻辑）、AgentTool 接口（工具定义）和 PendingMessageQueue（消息队列）。

Layer 3 / AI Abstraction

Provider 注册表模式

AI 抽象层通过 Provider 注册表支持多后端，包含流式处理、Token 估算和消息格式转换。

使用 ApiProviderRegistry 动态注册和获取 Provider，当前支持 Anthropic 和 MiniMax。

Layer 4 / Session

会话 持久化 与压缩

Session 层负责会话文件存储、恢复和消息压缩（compact）。

Entry 类型包括 header、user、assistant、toolResult 和 compact_boundary，通过文件追加写入和 compact 触发机制管理会话历史。

Layer 5 / TUI Rendering

Ink + React 终端 UI

TUI 渲染层使用 Ink 和 React 构建终端用户界面，包含消息列表、命令输入和状态栏。

关键组件有 App（根组件）、MessageList（消息渲染）、PromptInput（用户输入）和 StatusBar（底部状态栏）。

Data Flow

完整消息 流程

用户输入经 CLI → TUI → Agent → AI Provider → 工具执行 → Session 持久化的完整链路。

事件流通过 Agent.processEvents() 分发，TUI useAgent hook 监听并触发 React 状态更新。

Tech Stack

Bun + TypeScript 技术栈

运行时采用 Bun，语言为 TypeScript（strict 模式），TUI 框架使用 Ink + React。

AI/ML 依赖 @ai-sdk/anthropic、@anthropic-ai/sdk 和 ai 库，验证使用 Zod 和 @sinclair/typebox。

关键抽象

  • Agent - 状态化 Agent wrapper
  • runAgentLoop - 低层循环函数
  • AgentTool - 工具定义接口
  • SessionManager - 统一入口
  • ApiProviderRegistry - Provider 注册表

数据流

flowchart TD A[用户输入] --> B[CLI main.ts] B --> C[TUI App] C --> D[Agent.prompt] D --> E[runAgentLoop] E --> F[AI Provider] F --> G[executeToolCalls] G --> H[SessionManager.appendMessage] H --> I[SessionStorage.appendEntry] I --> J[文件追加写入]

事件流

flowchart TD A[AI Provider 流式响应] --> B[Agent.processEvents] B --> C[Event 类型分发] C --> D[message_start] C --> E[message_update] C --> F[message_end] C --> G[tool_execution_start] C --> H[tool_execution_end] C --> I[turn_end] D --> J[TUI useAgent hook] E --> J F --> J G --> J H --> J I --> J J --> K[React 状态更新] K --> L[UI 重新渲染]

技术依赖

  • Runtime: Bun
  • Language: TypeScript (strict)
  • TUI: Ink + React
  • AI: @ai-sdk/anthropic, @anthropic-ai/sdk
  • CLI: @commander-js/extra-typings
  • Validation: Zod, @sinclair/typebox
  • Web: Bun built-in HTTP
  • Logging: Pino
